# 조작 잠금 — R09 자체 아이디어

Basys3의 SW0로 시간·속도 설정과 시작·재개를 잠급니다. 실습 중 실수로 누른 버튼이나
로터리가 설정을 바꾸는 것을 막고, 취소·일시정지·문 개폐는 계속 사용할 수 있게 합니다.
문을 물리적으로 잠그는 장치나 실제 문 위치를 검출하는 기능은 아닙니다.

## 조작 계약

| 항목 | 동작 |
| --- | --- |
| SW0 아래(0) | 잠금 해제, 기존 조작 |
| SW0 위(1) | 조작 잠금, LD14 켜짐 |
| IDLE/PAUSED의 KEY | 잠금 중 시작·재개 차단 |
| RUN의 KEY | 잠금 중에도 일시정지 허용 |
| DONE의 KEY | 잠금 중에도 종료 알림 확인 허용 |
| btnL·btnU·btnD·로터리 | 잠금 중 필드·속도·시간 변경 차단 |
| btnR·btnC | 취소·전체 Reset 유지 |
| J3·L3 | 문 열기·닫기 유지 |
| 실행 중 SW0 올리기 | 기존 가열·계수 계속, 이후 설정 조작 차단 |
| SW0 내리기 | 자동 시작·재개 없음, 별도 KEY 필요 |
| 해제와 동시에 인식된 설정·KEY | 시작/재개·설정으로 사용하지 않음 |
| 잠금 해제까지 KEY를 계속 누르기 | 이전 누름을 재사용하지 않음, 놓고 다시 눌러야 시작·재개 |
| 버튼 소리 | 차단된 누름도 BEEP, SW0 자체에는 버튼 BEEP 없음 |
| Reset 후 SW0가 위에 있음 | 입력 안정화 후에도 잠금 유지 |

새 외부 배선은 없습니다. `lock_switch`는 보드 SW0의 FPGA 핀 V17을 사용합니다.
LD14는 이전의 1클럭 rotary_invalid 표시 대신 잠금 상태를 표시합니다.
rotary_invalid 신호 자체는 Top 내부에 유지해 Simulation에서 관찰할 수 있습니다.

## 구현 경계

`control_lock`은 입력 프런트엔드와 가열/모터 제어 사이에서 이벤트를 거릅니다.
시간·가열 FSM, 표시, 서보·도어의 기존 상태 전이와 출력 정책은 유지합니다.

SW0는 기존 `btn_debouncer`의 2단 동기화와 기본 10 ms 안정화 필터를 사용합니다.
Top에서 잠금 필터와 버튼 필터의 계수를 같게 연결하고, 프런트엔드의 `ready` 전에는
잠금으로 취급합니다. SW0를 올린 채 기동해도 필터 초기값 때문에 시작이 허용되지 않습니다.
단위 모듈을 다른 Top에 연결할 때도 `inputs_ready`는 잠금 입력 안정화 뒤에 올려야 합니다.
실제 스위치 전환이 논리에 반영되기까지 동기화·필터 지연이 있습니다.
해제 직후 한 클럭은 설정을 차단해 해제와 같은 클럭의 KEY·설정 이벤트도 버립니다.
RUN의 일시정지와 DONE 확인, 취소·개폐에는 이 추가 차단을 적용하지 않습니다.

가열/모터는 필터링된 이벤트를 받습니다. 도어와 부저는 원래의 버튼 이벤트를 받아
개폐·취소·BEEP 경로를 유지합니다. 잠금 해제는 이벤트를 저장하거나 재발행하지 않습니다.

## 검증

`tb_control_lock`은 네 가열 상태마다 128개 버튼 조합, CW/CCW, 입력 준비 전 차단,
스위치 잡음·잠금/해제 경계·해제와 동시 설정 차단·최소 계수·SW0가 올라간 상태의 Reset을 검사합니다.

`tb_top_control_lock`은 실제 Top 포트만 조작해 시작/재개 차단, 해제 시 눌린 KEY 및 해제와 동시 KEY,
실행 중 잠금, 계속되는 계수, 정지·개폐·취소, Reset, 만료·종료 확인·자동 복귀를 검사합니다.
기존 `tb_top_microwave_oven`은 SW0=0으로 고정해 이전 전체 동작을 회귀 검증합니다.
실제 실행 결과는 [검증 기록](verification.md)을 따릅니다.

새 기능의 실기 확인 순서는 다음과 같습니다.

1. 새 Bitstream 다운로드 후 SW0 아래에서 기존 조작 확인.
2. 5초 설정·문 닫기 → SW0 위·LD14 확인 → 시간/속도/KEY 조작 차단 확인.
3. KEY를 누른 채 SW0를 내려도 시작하지 않는지 확인하고, 놓고 다시 눌러 시작.
4. 실행 중 SW0 위 → 계속 동작 → KEY로 정지 → KEY 재개는 차단되는지 확인.
5. 잠금 중 문 개폐·취소·Reset 확인, 해제 후 별도 KEY로 재개.
6. 잠금 중 자연 만료와 3회 종료 알림·대기 복귀 확인.
