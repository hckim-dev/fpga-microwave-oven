# STEP 4 입력 Interface

`input_frontend`는 보드 핀 배정 이전의 논리적 입력 단위입니다.
최종 Top, 가열 FSM, 도어·모터·서보·부저·FND는 이번 단계에 포함하지 않습니다.

## 포트

| 포트 | 의미 |
| --- | --- |
| `clk` | 100 MHz 입력 클럭 |
| `reset` / `synced_reset` | active-high Reset 입력 / 비동기 인가·2클럭 동기 해제 |
| `tick_1ms` | 기본값에서 100,000클럭마다 발생하는 1클럭 enable |
| `button_raw[6:0]` | 아래 매핑의 원시 버튼 입력 |
| `rotary_ab_raw[1:0]` | `{S1,S2}`, 각각 동기화·debounce |
| `ready` | Reset 해제 후 입력 필터의 초기 안정화 대기 완료 |
| `button_down[6:0]` | 정규화된 버튼 상태. 누르면 1 |
| `button_pulse[6:0]` | 버튼 누름당 1클럭 이벤트. 동시 입력은 그대로 전달 |
| `rotary_cw`, `rotary_ccw` | 회전 단계당 1클럭 이벤트 |
| `rotary_invalid` | A/B가 동시에 바뀌는 유효하지 않은 전이 검출 이벤트 |

| 비트 | 예정 입력 | 기능 | 기본 극성 |
| --- | --- | --- | --- |
| 0 | btnL | 분/초 선택 | active-high |
| 1 | btnU | 속도 증가 | active-high |
| 2 | btnD | 속도 감소 | active-high |
| 3 | btnR | 취소 | active-high |
| 4 | J3 / JXADC 1번 | 열기 요청 | active-high, 외부 풀다운 |
| 5 | L3 / JXADC 2번 | 닫기 요청 | active-high, 외부 풀다운 |
| 6 | EC11 KEY | 시작/일시정지/재개 | active-low 가정, 실기 확인 필요 |

btnC는 이후 최종 Top에서 `reset`에 연결할 예정입니다. 핀 배정은 변경하지 않았습니다.
이번 모듈은 이벤트 우선순위를 결정하지 않습니다. 가열/도어 제어 단계에서 처리합니다.

## 시간과 극성 Parameter

모든 계수 Parameter는 양의 정수여야 합니다.

| Parameter | 기본값 | 계약 |
| --- | --- | --- |
| `TickCount` | 100,000 | tick 주기, 1도 지원 |
| `ButtonDebounceCount` | 1,000,000 | 버튼의 연속 안정 기간 10 ms |
| `RotaryDebounceCount` | 200,000 | A/B의 연속 안정 기간 2 ms |
| `StepsPerDetent` | 4 | 유효 전이의 순누적량. 실제 EC11에 맞춰 2 또는 4 확인 |
| `ButtonActiveLow` | `7'b1000000` | 해당 비트가 1이면 입력 극성 반전 |

입력은 2단 동기화 뒤 필터링합니다. 안정 시간은 **동기화된 입력** 기준입니다.
`ready`는 두 필터 계수 중 큰 값에 4클럭 여유를 둔 후 활성화됩니다.
기동 또는 Reset 해제 시 이미 눌린 버튼은 상태만 반영하며 누름 이벤트를 만들지 않습니다.
이 버튼은 떼었다 다시 눌러야 이벤트가 발생합니다. 기동 중 들어온 조작은 보장 범위 밖입니다.

CW 전이 순서는 `00 -> 10 -> 11 -> 01 -> 00`입니다.
반대 방향 전이는 누적량을 상쇄하므로 중간에 되돌아온 움직임을 완전한 회전으로 세지 않습니다.
유효하지 않은 전이는 누적량을 폐기하고 현재 위상부터 새로 추적합니다.
Reset 또는 초기 위상 저장 자체로 회전 이벤트를 만들지 않습니다.

## 실기 확인 항목

- EC11 미누름 KEY 극성과 CW 방향, 클릭당 전이 수.
- 빠른 회전에서 2 ms 필터가 유효 전이를 누락하는지 여부.
- J3/L3 입력이 미누름 0, 누름 1인지 확인.
- Reset 중 및 해제 직후 이벤트 없음, 길게 누를 때 반복 이벤트 없음.

해당 항목은 아직 실제 보드에서 확인하지 않았습니다. 향후 보드용 Top과 XDC를 준비한
검증 시점에 상태/이벤트를 LED 등에 연결하여 확인합니다.
