# 실기 시연 촬영 계획

기본 기능과 SW0 잠금은 사용자 정상 동작 확인 상태입니다. 아래는 아직 촬영하지 않은
영상의 계획·자막안이며 실제 영상이 존재한다는 뜻은 아닙니다.
총 약 2~3분은 편집 목표 분량으로, 실제 촬영/발표 시간을 측정한 값이 아닙니다.

## 촬영 준비

- 보드 FND·버튼·LD14, 서보 문, 모터가 함께 보이는 전체 사진 1장.
- 배선과 부품 이름을 식별할 수 있는 사진 1장. 화면 표기는 [연결표](integration.md)와 대조.
- 각 장면은 처음과 끝에 2초 정도 정지 화면을 두고, 손이 FND와 문을 가리지 않게 촬영.
- BEEP·개폐·종료음을 들을 수 있도록 원본 음성을 함께 녹음.
- SW0=0, Reset, 문 닫기부터 시작. 도어는 명령 기반 추정임을 설명에 유지.

V06에서는 실행 중 잠금을 올려도 계속 동작하는 장면과 KEY 정지가 허용되는 장면을
이어 보여줍니다. 정지 상태에서는 잠금을 해제하고 KEY를 다시 눌러야 재개합니다.
잠금·해제의 같은 클럭 경계는 손동작 영상으로 타이밍을 증명하지 않고
[Simulation 파형](evidence/README.md)을 함께 사용합니다.
