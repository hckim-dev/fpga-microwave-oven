직접 작성한 코드와 구분해 원문을 보존했습니다.

## 이름·구조·최적화 판단

- 파일과 모듈은 snake_case, Parameter는 기존 PascalCase, FSM 상수는 기존 대문자 규칙을 유지했습니다.
- 내부 r_는 저장 상태, w_는 조합 계산이라는 기존 구분을 유지했습니다. Verilog의 조합 reg도 w_에 해당합니다.
- Top 연결 신호·공개 포트·인스턴스·TB의 계층 참조 이름을 불필요하게 바꾸지 않았습니다.
- 입력 정규화·가열·표시·소리·도어·서보·모터의 책임과 단일 클럭 구조를 유지했습니다.
- Top의 button_down/duty_percent/timeout_pulse/sound_busy 등은 관찰·TB 연결에 쓰는 신호입니다.
  사용하지 않는 출력 포트를 없애기 위해 모듈 계약을 바꾸지 않았으며 합성에서 불필요한 논리는 제거됩니다.
- 상수 나눗셈을 BCD 카운터로 바꾸거나 FSM·FIFO·부저 모드를 재구성할 성능 근거는 없습니다.
  LUT 785개(3.77%), FF 436개(1.05%)와 Timing이 정리 전후 동일합니다.
- active 부저 모드의 반송파 제거와 모듈별 미사용 버튼 비트 경고는 기존 의도와 일치합니다.
  경고를 감추는 설정이나 dummy 로직은 추가하지 않았습니다.

### 발견하고 수정한 항목

P2 — `check_repository.py`가 다음 잘못된 설정도 PASS로 처리하는 것을 파일 변경 없는
fixture로 재현했습니다. 현재 실제 보드 설정은 정상입니다.

- FPGA Part를 다른 디바이스로 바꿔도 검사하지 않았습니다.
- Design Top을 등록된 다른 모듈로 바꿔도 허용했습니다. 활성 보드 XDC와 맞지 않습니다.
- 핀 배정 줄을 주석 처리해도 정규식이 배정으로 집계했습니다.
- 클럭 제약을 주석 처리해도 검사하지 않았습니다.

Part와 보드 Design Top을 명시적으로 확인하고, 주석 줄을 제외한 활성 핀·클럭만 검사하도록
수정했습니다. 보드 클럭은 sys_clk·clk 입력·10 ns 하나여야 합니다.
기존 Vivado 읽기 전용 검사도 보드 Design Top을 동일하게 확인합니다.
등록된 단위 TB를 Simulation Top으로 선택하는 동작은 허용합니다.

`test_repository_checks.py`의 9개 검사는 정상 저장소, 잘못된 Part/Design Top,
단위 Simulation Top 허용, 주석 처리 핀/클럭, 잘못된 주기, 추가 클럭,
주석 처리된 중복 핀의 무시를 확인합니다. 실제 XPR·XDC 파일은 수정하지 않습니다.

P3 — 요구사항 R06의 취소 설명에서 서보 출력 차단 범위를 명확히 했습니다.
이동 중 취소는 서보를 차단하지만, 안정된 OPEN/CLOSED 위치에서는 유지 펄스를 계속 보냅니다.
RTL 정책 변경이 아닌 설명의 정정입니다.
