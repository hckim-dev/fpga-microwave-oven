# 실제 하드웨어 확인

2026-10-28, 사용자는 기본 기능과 새 Bitstream의 SW0 조작 잠금이 정상 동작한다고 확인했습니다.
이는 일반 동작 보고이며 아래 각 경계 조건의 개별 PASS 기록은 아닙니다. 항목별 측정값·영상은 아직 저장소에
기록하지 않았습니다. SG90의 개폐 후 소음·떨림은 사용자가 자연스러운 동작으로
수용해 종결했습니다. 서보 펄스·위치 유지 정책은 그대로입니다.
아래 표는 확인 순서이며 자동으로 실기 PASS를 의미하지 않습니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| EC11 회전 | 선택 필드 ±1, 분·초 각각 0~59 포화 |
| btnL | 분/초 선택, IDLE에서만 편집 |
| EC11 KEY | 시작·일시정지·재개, DONE에서는 알림 확인 |
| J3 / L3 | 문 열기 / 닫기, 외부 풀다운 유지 |
| btnU / btnD | 모터 PWM 30/50/70/90%, 기본 50% |
| btnR | 취소, 시간 초기화·속도 유지 |
| btnC | 전체 Reset, 속도 50%·도어 UNKNOWN |
| SW0 | 1=조작 잠금·LD14, 0=해제 |

## 확인 순서

Program Device에서 검증한 `microwave.bit`를 선택합니다. 위치는
[검증 기록](verification.md)의 해당 빌드 경로를 따릅니다.
기본 기능 확인은 SW0=0에서 진행합니다. 첫 개폐는 링크를 분리한 상태에서
방향·가동 범위를 확인한 뒤 기구에 맞춰 보정합니다.

| 순서 | 조작 | 기대 결과 | 기록 |
| --- | --- | --- | --- |
| 1 | 다운로드 후 btnC | 00.00, LD0/LD7, 모터 정지, 서보 자동 이동 없음 | 미기록 |
| 2 | btnU 길게 누르기 | 50→70% 한 번만 변경 | 미기록 |
| 3 | btnU를 누른 채 Reset 해제 | 50% 유지, 놓고 다시 누르면 70% | 미기록 |
| 4 | EC11 양방향·btnL | 한 detent ±1, 분/초 선택과 점멸 일치 | 미기록 |
| 5 | 각 필드를 상·하한까지 회전 | 0~59 포화, 다른 필드 유지 | 미기록 |
| 6 | 5초 설정 후 UNKNOWN/열림에서 KEY | 실행 차단 | 미기록 |
| 7 | J3, 완료 후 L3 | LD6→LD5/LD4, 실제 개폐·효과음 | 미기록 |
| 8 | 0초에서 KEY | 실행 차단 | 미기록 |
| 9 | 닫힌 뒤 10초 설정·KEY | LD1, 회전, 시간 감소·circle 화면 교대 | 미기록 |
| 10 | 실행 중 btnU/D·로터리·btnL | 속도 네 단계, 시간 편집 차단 | 미기록 |
| 11 | KEY 후 2초 대기·속도 변경·KEY | LD2, 시간 보존·DP 점멸, 변경 속도로 재개 | 미기록 |
| 12 | 실행 중 J3·KEY·L3 | 중단, 열린 동안 재개 차단, 닫기만으로 재개하지 않음 | 미기록 |
| 13 | KEY 재개 후 btnR | 시간 0·모터 구동 차단·속도 유지 | 미기록 |
| 14 | 개폐 시작 후 약 0.5초 안에 취소 | LD7, 서보 출력 차단, 개폐 요청으로 복구 | 미기록 |
| 15 | 01.01로 시작 | 01.00→00.59 경계 확인 후 취소 | 미기록 |
| 16 | 5초 동작을 끝까지 대기 | 모터 차단·LD3·0000/소리 3회·IDLE 복귀 | 미기록 |
| 17 | 다시 종료 알림 중 KEY 또는 btnR | 알림 중단·IDLE 복귀 | 미기록 |
| 18 | 실행/개폐 중 btnC | 출력 차단·시간 0·속도 50%·도어 UNKNOWN | 미기록 |

위치 LED는 센서 측정값이 아닌 명령·시간 기반 추정입니다. 모터 출력 차단과
관성에 의한 회전 종료는 구분합니다. 부품 전원·구동 조건의 적합성은 별도 확인 대상입니다.

SW0 조작 잠금은 사용자 정상 확인 상태입니다. [조작 잠금](control_lock.md)의 6단계는
상세 결과 기록과 촬영 때 활용합니다. 해제·KEY 동시 인식의 클럭 경계는
[실제 Simulation 파형](evidence/README.md)으로 보완합니다.

## 관찰과 상태

| 항목 | 현재 상태 | 기록할 내용 |
| --- | --- | --- |
| SW0 조작 잠금 | 사용자 정상 확인 | 항목별 결과·사진/영상은 미확보 |
| SG90 개폐 후 소음·떨림 | 사용자 판단으로 종결 | 자연스러운 위치 유지 동작으로 수용, 구동 코드 유지 |
| 서보 목표·이동 대기 | 1/1.5 ms, 500 ms 초기값 | 실제 각도·방향·도착 시간 |
| 모터 네 속도 단계 | PWM 논리 검증 완료 | 기동 여부·실제 회전 변화, RPM 주장은 측정 시에만 |
| 부저 | 기본 ON/OFF 모드 | 부품 종류·리듬·청취 결과 |
| 최종 증거 | 미확보 | 항목별 결과와 자막 포함 동작 영상 |
